# Gmers: folder kerja

Aplikasi chat + game sosial (Ludo, Remi, Gaple). Pembaruan terakhir 12 November 2026.

## Isi
- `CLAUDE.md`: aturan kerja dan keputusan terkini (dibaca otomatis Claude Code)
- `docs/`: paket spesifikasi dan implementasi
  - `01-spesifikasi.md` (sumber kebenaran perilaku), `02-erd.md`, `schema.sql`, `erd/`
  - `03-rencana-tahap.md` (termasuk Tahap MVP Uji), `tahap/NN-*.md`, `tahap-gabungan.md`
  - `04-aturan-remi-draf.md` (draf, varian belum dikunci)
  - `CATATAN-TAHAP.md` (diisi Claude Code setiap akhir tahap)
- `prototipe/gmers-prototipe-v14.html`: prototipe klik (acuan tampilan, bukan kode)
- `web/`: landing page dan `demo/` dengan mode uji (`?uji=1`)
- `cloudflare/gmers-landing-mode-uji.zip`: zip untuk diunggah manual ke proyek Cloudflare Pages `gmers`
- `strategi/`: rancangan lengkap dan tautan dokumen online (Claude Docs)
- `simulasi-ekonomi-game-v3.md` / `.xlsx`: simulasi ekonomi
- `Gmers Strategi Menjadi Snapchat-nya Main Bareng.pptx`: deck strategi (diperbarui 12 Nov 2026)

## Mulai
Untuk membangun: baca `CLAUDE.md`, lalu `docs/03-rencana-tahap.md`. Tahap MVP Uji dikerjakan sebelum Tahap 00.
